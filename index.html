☁️ Kết nối Cloud cho “2 Đứa Cute”

Để Vân Anh và Thùy Em cùng nhập trên 2 thiết bị và thấy số liệu gần như ngay lập tức, web cần một database online. File này dùng Firebase Realtime Database. File này đã có sẵn Firebase Web App config của project chitieu2026nha; bạn không cần nhập lại trên từng thiết bị.

Firebase setup nhanh:
  1. Tạo project Firebase và Web App.
  2. Tạo Realtime Database — bạn đã tạo xong.
  3. Để test nhanh có thể dùng Test mode. Sau khi ổn định, bật Anonymous Authentication và chuyển Rules sang auth != null.
  4. File HTML này đã được gắn sẵn Web App config + database URL của project.
  5. Sau khi test ổn, mình sẽ giúp bạn khóa Security Rules để bảo vệ dữ liệu.

Test mode hiện tại:

{
  "rules": {
    ".read": true,
    ".write": true
  }
}
