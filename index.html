☁️ Kết nối Cloud cho “2 Đứa Cute”

Để Vân Anh và Thùy Em cùng nhập trên 2 thiết bị và thấy số liệu gần như ngay lập tức, web cần một database online. File này dùng Firebase Realtime Database. Bạn chỉ cần nhập Firebase Web App config một lần trên mỗi thiết bị.

Firebase setup nhanh:
  1. Tạo project miễn phí tại Firebase Console.
  2. Enable Authentication → Anonymous.
  3. Tạo Realtime Database.
  4. Add Web App và copy 6 thông số config bên dưới.
  5. Trong Realtime Database Rules, cho phép authenticated users đọc/ghi dữ liệu của app.

Realtime Database Rules:

{
  "rules": {
    ".read": "auth != null",
    ".write": "auth != null"
  }
}
